# BANDHU 🤝

> *Your friend in every meeting*

A private, free AI meeting companion for non-native English speakers. Listens to meetings, converts any accent or language into Simple English or Telugu, and auto-extracts your action items.

## 🔗 Try it
👉 **https://YOUR-USERNAME.github.io/bandhu/**

Best on **Chrome (Android)**. Tap the mic, allow permission, start your meeting.

## ✨ What it does
- 🎤 Real-time speech transcription
- ✨ Converts corporate jargon to Simple English ("synergize" → "work together")
- 🔵 Translates to Telugu
- 📌 Auto-extracts action items assigned to you
- ✅ Tap to mark done, saved on your device

## 🔒 Privacy
- 100% private — runs in your browser
- No account, no login, no tracking, no ads
- Nothing stored on any server

## 💰 Cost
Free. Forever. For everyone.

## 🛠️ Tech
Web Speech API · MyMemory Translation · Vanilla JS · Zero dependencies
